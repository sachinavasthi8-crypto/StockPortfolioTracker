📈 Stock Portfolio Tracker — Python

A simple stock portfolio tracker built with Python as part of my CodeAlpha Python Programming Internship.
📌 About the Project
This project allows users to track their stock investments.
The user enters stock names and quantities, and the program automatically
calculates the total investment value using hardcoded stock prices.
The result can also be saved as a CSV file.

✨ Features

Displays list of available stocks with prices (AAPL, TSLA, GOOGL, TCS, Reliance, etc.)
User can input multiple stocks and quantities
Calculates total investment value automatically
Option to save portfolio summary as a CSV file
Clean and formatted output in the console

🛠️ Technologies Used

Python 3
Libraries: csv, datetime (both built-in)

▶️ How to Run

Make sure Python is installed on your system
Download or clone this repository
Open terminal and run:

python task2_stock_tracker.py

🧠 Key Concepts Used

Dictionary
User Input / Output
Basic Arithmetic
File Handling (CSV)
datetime module
